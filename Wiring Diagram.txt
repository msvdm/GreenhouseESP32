# Greenhouse Controller - Wiring (firmware 8.x)

Board: ESP32-WROOM-32E 2-channel relay module, 7-60 V DC (or 5 V) supply.
All grounds common. Relays are on the board - no transistors needed.

## Relays (onboard)

```
Relay 1 (GPIO 16) - CEILING FANS
  COM  <- L (fused)
  NO   -> fans L          fans N -> N

Relay 2 (GPIO 17) - HEATER CONTACTOR COIL
  COM  <- L (fused, control circuit)
  NO   -> contactor A1    contactor A2 -> N
  The contactor's main contacts switch the 1200 W radiant heaters.
```

Relay contacts are rated 10 A / 250 VAC. Switch the heaters through the
contactor, never directly through the board relay. Fit an RC snubber across
the contactor coil if the board resets or the screen glitches when it switches.

## DS18B20 sensor lines

Two independent lines. Any number of probes per line (up to 8), wired in
parallel; they are found automatically.

```
Line 1 -> GPIO 4        Line 2 -> GPIO 15
  each probe: red -> 3V3, black -> GND, yellow -> data
  one 4.7 kOhm pull-up from data to 3V3 per line
```

GPIO 15 is a strapping pin; the pull-up keeps it HIGH at boot, which is correct.

## ST7735 1.8" TFT (160x128)

```
TFT    ESP32
VCC -> 3V3 (or 5 V if the module has a regulator)
GND -> GND
CS  -> GPIO 25
RST -> GPIO 33
A0  -> GPIO 27  (DC)
SDA -> GPIO 26  (MOSI)
SCK -> GPIO 18
LED -> 3V3 (via resistor if the module has none)
```

Changed in 8.1.0: the display no longer uses GPIO 2, 21, 22 or 23.

## Free / reserved

GPIO 0  - IO0 button (hold 5 s while running = password + AP factory reset)
GPIO 23 - onboard LED, status light (see README)
GPIO 19 - leave unconnected (SPI driver claims it as MISO input)
Free    - 2, 5, 13, 14, 21, 22, 32
